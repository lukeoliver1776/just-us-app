Requirements

Install the following software before launching the application:

  • Java 17
  • Apache Maven
  • Git

Launch Instructions

  1. Open a terminal.
  2. Clone the repository: 
    git clone https://github.com/lukeoliver1776/just-us-app.git
  3. Enter the project folder: 
    cd just-us-app
  4. Run the automated tests: 
    mvn test
  5. Start the JavaFX application: 
    mvn javafx:run
  6. Wait for the Just Us window to appear.
  7. Enter a name for player one.
  8. Enter a name for player two.
  9. Select the Start Game button.
