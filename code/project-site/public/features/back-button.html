Instructions

  1. Start a tic-tac-toe game.
  2. Locate the Back button above the game board.
  3. Select the Back button.
  4. The application will return to the room page.
  5. Enter player names again to begin a new game.

Returning to the room page ends the current game. The current game and player names are not saved.
