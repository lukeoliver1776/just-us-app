Instructions

  1. Create a room with two player names.
  2. Select the Start Game button.
  3. Player one starts the game using the X mark.
  4. Select an empty square to place the X mark.
  5. Player two selects an empty square to place the O mark.
  6. Continue taking turns until a player wins or the board is full.
  7. Read the message above the board to see the current turn or result.

A player wins by placing three matching marks in a row, column, or diagonal.
