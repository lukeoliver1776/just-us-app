Create a Two-Player Room

Home Documentation

Instructions

  1. Launch the Just Us application.
  2. Locate the Player one's name field.
  3. Enter the first player's name.
  4. Locate the Player two's name field.
  5. Enter the second player's name.
  6. Select the Start Game button.
  7. The tic-tac-toe game page will open.

Both fields are required. The application displays an error message if either player's name is blank.
