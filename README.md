### just-us-app

## Just Us

Just Us is a two player online boardgame platform built primarily for long distance couples. As someone who long distance dated, I found gaps in online platforms that were designed to be connecting for couples, but fell short. Rather than acting as a generic multiplayer games site, it's designed around a "intimacy" goal. every feature should make shared time with your significant other feel more personal and connected. Each couple gets a permanent, private, and persistent 2 seat room combining a game launcher with room specific stats and history. Starting with a simple tic tac toe game as proof of concept and expanding to other classic games like chess, Uno, and Scrabble. 

The value of this project is not monetary, but personal. It grew out of my own experience long distance dating my (now) wife, using simple online games as a way to stay connected across timezones and distance. Building this system lets me explort both the complexion and technical challenge of real time server authentication/authority multiplayer games states using web sockets, session recconnection challenges, personable ui and the other challenge of desiging for a niche, relationship based use case rather than maximizing monetization or generic engagement.
